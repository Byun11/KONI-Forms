# Privacy Policy for KONI Forms

## Introduction

[KONI Forms](https://github.com/Byun11/KONI-Forms) is a Chrome extension that runs an AI web agent in your browser. This Privacy Policy explains how your data is handled.

## Open Source

KONI is licensed under the Apache License 2.0 and is built on the open-source nanobrowser project. The source code is available in the [GitHub repository](https://github.com/Byun11/KONI-Forms).

## Data Collection and Processing

### Local Processing
- KONI operates within your browser
- Login credentials and cookies never leave your browser
- KONI does not collect analytics or usage statistics

### LLM Provider Interactions
When you run a task, the page content and the documents you attach are sent directly to the LLM provider you chose. This is necessary for the AI features to work. That data is subject to your LLM provider's privacy policy. With a local provider such as Ollama, it stays on your machine.

## API Keys
- You provide your own API keys for LLM providers
- Keys are stored locally in your browser only
- You manage key security per provider terms

## User Control
- Clear conversation history and settings anytime
- Uninstall the extension to remove all local data

## Changes to This Privacy Policy
This policy may be updated periodically. Please review it for changes.
